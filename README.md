# Flash Paper Fire

플래시 페이퍼(니트로셀룰로스 종이)가 순식간에 타면서 강한 빛을 내고 재 없이 사라지는 모습을 브라우저에서 재현한 fire effect입니다. 의존성 없이 `index.html` 하나(Vanilla JS + Canvas 2D)로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.

## 조작

- **왼쪽 클릭 / 누르고 있기**: 라이터로 불 붙이기
- **휠 버튼 드래그**: 종이 돌리기 (놓으면 관성으로 조금 더 돌다 멈춤)
- **R**: 리셋
- **속도 슬라이더**: 불이 번지는 속도
- `index.html?slow=0.2`: 슬로모션

## 모드

- **플래시 페이퍼**: 떠 있는 종이 한 장이 번쩍 타고 사라짐
- **도화선 → 스마일맨**: 나무판 위 종이띠가 오르막을 타고 올라가 끝의 막대인간 카드를 태움
- **도화선 → 텍스트**: 입력한 글자(한글·영문, 최대 24자)를 종이로 오려 선반 위에 세우고, 오르막 도화선이 선반을 따라가며 글자를 차례로 태움. 떨어진 획(예: `이`의 `ㅇ`)에도 열이 건너가 불이 붙습니다.

## 구현

- **연소**: 종이를 3px 셀 격자로 나눈 셀룰러 오토마타. 이웃 셀로 확률적으로 옮겨붙고(위쪽이 더 빠름), 부드러운 노이즈로 셀마다 가연성이 달라 불 경계가 자연스럽게 들쭉날쭉합니다.
- **불길**: 타는 셀이 열을 주입하는 5px 열 필드. 매 프레임 열이 위로 이류(semi-Lagrangian)되고 좌우로 흔들리며, 위로 흘러가는 노이즈 텍스처로 불균일하게 식어서 불꽃 혓바닥 모양이 생깁니다. 온도는 흰색 → 노랑 → 주황 → 빨강 팔레트로 매핑하고 블룸을 더해 가산 합성합니다.
- **빛**: 타는 면적에 비례한 주변광과 짧은 과노출.
